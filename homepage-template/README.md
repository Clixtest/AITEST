# Futuristic Personal Homepage Template

This is a modern and colorful personal homepage template. It features:

- Dynamic hero section
- Portfolio display
- Contact form with simple client-side handler
- Easy customization via CSS variables and JavaScript constants

## Customization

1. Edit `index.html` to add your content.
2. Adjust colors and fonts in `css/style.css` (see the `:root` variables).
3. Update `js/script.js` to set your name or add additional interactivity.
4. Replace images in the `images` folder with your own graphics.

The template uses only HTML, CSS, and vanilla JavaScript, making it easy to edit without any build tools.
